Architecture & PoC — Cheat Sheet

Condensed exam notes and a reference architecture, kept separate from the Build Log (what was actually deployed). This describes the fuller "if it were a real multinational bank" reference architecture the exam scenario points at — broader in scope than the PoC.

1 · Entry, Networking & Auth

AWS Global Accelerator
2 static anycast IPs, routes over the AWS private backbone. Use for global users needing low-latency WebSocket/TCP streaming and static-IP whitelisting (bypasses public-internet jitter).
AppSync & WebSockets
Real-time token streaming via GraphQL subscriptions. To beat AppSync's 30s integration timeout on long LLM responses: an async mutation returns a conversationId immediately, then a persistent WebSocket subscription streams tokens.
Amazon Cognito & JWT
Stateless token verification at the AppSync layer. For instant session revocation, pair short-lived JWT TTLs with a revocation check against a fast key-value store (Redis/DynamoDB).

2 · Core RAG & Knowledge Base

Bedrock Knowledge Base
Fully managed, serverless RAG orchestration — handles ingestion, chunking, and embedding generation.
Multilingual Embeddings
No explicit translation step needed — queries map directly into a cross-lingual vector space, so a query in one language matches document chunks in another.

3 · Vector Store Decision Matrix

OpenSearch Serverless
The default, ultra-low-latency vector engine. Critical exam rule: mandatory when a Bedrock KB ingests SaaS sources like SharePoint, Salesforce, or Confluence.
Amazon S3 Vectors
Cost-optimized for massive-scale datasets where sub-second latency is acceptable.
Aurora (pgvector)
When the app must keep leveraging an existing relational PostgreSQL database.
Neptune Analytics
GraphRAG — multi-hop relationship traversal, entity-connection discovery (e.g. fraud networks) via nodes/edges.

4 · Safety, Governance & Guardrails

Bedrock Guardrails
An independent safety net outside the raw inference path — filters both input and output.
PII Masking
Auto-detects and redacts sensitive data (SSNs, phone numbers, credit cards) from inputs and outputs.
Contextual Grounding
Scores hallucination risk by checking whether the response is actually supported by the retrieved KB chunks.

5 · Async Integration & Audit Plane

Amazon EventBridge
Decoupled, multi-target, content-based router via PutEvents (fire-and-forget) — triggers parallel, non-blocking post-processing.
Amazon SQS
A shock absorber / rate limiter — buffers traffic spikes, and routes flagged low-confidence interactions into a compliance review queue without taking down downstream workers.

6 · Orchestration Patterns

Bedrock Flows
Deterministic, node-based. Use when the execution path must be a rigid, 100% predictable sequence (regulatory compliance, audit pipelines).
Bedrock Agents
Non-deterministic (ReAct pattern). Use when the LLM must dynamically reason about which tools/Lambda APIs to call at runtime.

7 · Build vs. Buy

Amazon Q Business
Fully managed, turn-key enterprise search with built-in connectors — zero custom pipeline for rapid employee-search needs.
Amazon Bedrock
Managed serverless APIs for frontier models (Claude, Llama, Titan) + custom RAG/Guardrails/Agents.
SageMaker JumpStart/Training
Deep custom fine-tuning (LoRA, RLHF) and full control over the underlying GPU infrastructure.

8 · GenAIOps, Observability & Monitoring

AWS X-Ray
End-to-end distributed tracing across AppSync → Lambda → Bedrock KB → vector store → LLM, to isolate latency bottlenecks.
Bedrock Model Invocation Logs
Captures raw prompts and completions to S3/CloudWatch Logs for audit and compliance.
Model Evaluation
Automated metrics (ROUGE/BLEU, toxicity scripts) plus structured human evaluation loops.
