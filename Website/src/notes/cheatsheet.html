Domain 1

Foundation Models, Data & Compliance

31% of the exam

1.1Architecture & PoC

  • Global Accelerator gives 2 static IPs on the AWS backbone — global users, IP whitelisting.
  • AppSync times out at 30s: return a conversationId immediately, stream over a subscription.
  • Cognito JWTs are stateless; instant revocation needs short TTLs plus a Redis/DynamoDB check.
  • OpenSearch Serverless is mandatory for SaaS connectors (SharePoint, Salesforce, Confluence).
  • S3 Vectors for huge and cheap, Aurora pgvector for existing Postgres, Neptune for multi-hop graphs.
  • Flows are deterministic and auditable; Agents reason at runtime and vary.
  • Q Business turnkey, Bedrock managed APIs, SageMaker full control and fine-tuning.
  • EventBridge is fire-and-forget fan-out; SQS is the shock absorber in front of slow workers.

1.2FM Selection & Lifecycle

  • Set the quality thresholds before testing, or results get rationalised afterwards.
  • Filter on capability first — multimodal, context window — before benchmarking anything.
  • Few-shot pays tokens on every call and drifts; fine-tuning bakes the behaviour in.
  • LoRA freezes the base model and trains an adapter under 1% of parameters, swappable.
  • 100–300 curated JSONL pairs is the scale for a fine-tune.
  • Three gates: automatic metrics, then an LLM judge, then human sign-off.
  • Latency and cost are not part of model evaluation — that is a load test.
  • BLEU is precision, ROUGE is recall; both are word overlap, so both pass a flipped negation.
  • Data drift here means new drugs and revised codes, not a software bug.

1.3Data Preparation

  • Five stages: validate, process and fuse, format, enrich, then infer.
  • Glue Data Quality catches known rules, Data Wrangler finds unknown ones, Lambda does domain logic.
  • Data that fails validation goes to a human queue — never silently dropped.
  • Step Functions, not Lambda, when a job can outrun the 15-minute limit.
  • Comprehend, Rekognition and Transcribe run in parallel, then fusion exposes contradictions.
  • Temperature 0.0–0.2 when the same input must give the same answer tomorrow.
  • Tune temperature or top-p, never both — the effects overlap and you cannot debug it.
  • max_tokens caps the output only, not the prompt.
  • Models are stateless: resend history, and compress old turns to avoid token bloat.
  • Clean text with a small cheap model before an expensive one reads it.

1.4Vector Stores

  • Bedrock KB for managed, OpenSearch for confidential and hybrid, DynamoDB for live flags.
  • The neural plugin embeds the query for you at search time.
  • Filter on metadata in a relational store first, then do vector maths on the shortlist.
  • Shard the index by jurisdiction or practice area so a query scans one shard, not all.
  • Cache the hot, repeated lookups — standard clauses, boilerplate.
  • Metadata can overrule similarity: a perfect match that was overturned must still be blocked.
  • Fine-grained access control is evaluated before the vector search, not after.

1.5Retrieval Design

  • Chunking options: fixed, structure-aware, hierarchical parent–child, semantic, none, Lambda custom.
  • Default is ~300 tokens, with about 10% overlap so split sentences survive.
  • Choose the chunking strategy per document type, not once for the whole corpus.
  • Attach metadata while chunking — adding it later means re-ingesting everything.
  • Titan Text Embeddings is 1,536 dimensions; V2 also offers 1024, 512 and 256.
  • Dense vectors carry meaning, sparse carry exact terms; binary cuts storage ~32×.
  • Use the same embedding model for ingest and query or the whole space shifts.
  • Hybrid search is set with OverrideSearchType = HYBRID.
  • Two-stage: retrieve ~100 cheaply, rerank down to 10 with cross-attention.
  • Query expansion adds up to 23% recall; decomposition cuts up to 40% latency.
  • Multi-tenant: silo, pool or bridge — and a pool filter belongs in the query, not the client.
  • Scrub PII before embedding; once it is in the vector it cannot be removed.

1.6Prompt Engineering & Governance

  • Three layers: the prompt instructs, guardrails block, JSON Schema enforces shape.
  • Guardrails sit outside the model and the prompt, so injection cannot switch them off.
  • Content filters cover hate, insults, sexual and violence; your own words go in word filters.
  • Session state in DynamoDB: PK session_id, SK timestamp; a 90-day TTL is a compliance control.
  • Intent confidence below 0.70 should ask a clarifying question, not guess.
  • Versioned prompts roll back by moving a pointer from v8 to v7 — no redeploy.
  • Author, compliance reviewer, deployer: nobody ships their own prompt.
  • CloudTrail keeps API metadata for years; CloudWatch Logs keeps the payloads for debugging.
  • A golden dataset blocks a deploy that fixes one scenario and breaks another.
  • Chain-of-thought works because tokens are generated in order, so reasoning becomes context.
  • Human escalation rate rising while errors stay flat means the model is failing quietly.
Domain 2

Implementation and Integration

26% of the exam

2.1Agentic AI & Tools

  • The loop is Reason, Act, Observe — repeat until a stopping condition.
  • An agent is a model plus instructions plus action groups; knowledge base and guardrails optional.
  • Memory in three tiers: session (ElastiCache), working (DynamoDB), long-term (S3 or a KB).
  • Step Functions ReAct fixes the shape of the loop while the model still reasons inside it.
  • Five layers stop a runaway: IAM, input validation, timeouts, stopping conditions, circuit breaker.
  • Action groups are not a security boundary. IAM is.
  • Above 0.9 run it, 0.7–0.9 review after, below 0.7 wait for approval.
  • Wait tokens pause the workflow and keep state, with a 24-hour fallback.
  • The OpenAPI description is what the model reads, so vague descriptions pick the wrong tool.
  • Return errors the model can act on — valid alternatives, not a bare 404.
  • MCP is portable across clients; action groups are Bedrock-only.

2.2Deployment Strategies

  • An LLM is 100–500 GB where a classic model is 50 MB — every habit changes.
  • Loading takes 20 to 40 minutes against a 5–10 minute default health check: raise it to 60.
  • Shard across GPUs with DeepSpeed, Triton or FasterTransformer when it will not fit.
  • Quantization walks FP32 to FP16 to INT8 to INT4, trading accuracy for memory.
  • Size provisioned capacity as peak RPS × average tokens → TPS → Model Units.
  • SageMaker endpoints: real-time, serverless, asynchronous, batch transform.
  • Lambda invokes models, it never hosts them.
  • Custom Model Import gives you a fine-tuned model on pay-per-token instead of a 24/7 GPU.
  • Cascading only pays off if most queries really are simple — escalation costs two calls.
  • Embedding cache and response cache are different things with different keys.
  • Multi-model endpoints break on big LLMs because the cold start is minutes.
  • GPU utilisation near 20% means oversized; a cache hit rate under 5% means pointless.

2.3Enterprise Integration

  • API Gateway mapping templates translate SOAP and XML both ways so legacy stays untouched.
  • Reserved concurrency caps a function; provisioned concurrency pre-warms it.
  • EventBridge filters on patterns, and failures go to a dead-letter queue, not nowhere.
  • Parallel state runs different jobs at once; Map state runs one job over many items.
  • Glue for data lakes and bulk ETL, AppFlow for SaaS connectors.
  • Use Amazon MQ only because the legacy side already speaks JMS or AMQP.
  • Webhooks arrive at least once — dedupe on event id in DynamoDB with a TTL.
  • SQS FIFO keeps order inside a message group while other groups run in parallel.
  • IAM Identity Center is for staff, Cognito for customers; a pre-token Lambda injects claims.
  • IAM says whether you may call Bedrock; Cedar says whether you may see this document now.
  • PrivateLink endpoint policies can restrict to one model and to InvokeModel only.
  • WAF rate rules are billing protection as much as security.
  • Outposts for residency, Local Zones for metro latency, Wavelength for 5G.
  • Black-hole routes guarantee no path from dev to prod; Network Firewall blocks exfiltration.
  • The GenAI Gateway centralises auth, quotas, chargeback, guardrails, caching and audit in one place.

2.4FM API Integrations

  • Size timeouts by the work: 4–5s interactive, 15–30s simple, up to 120s for long generation.
  • Back off 100, 200, 400, 800 ms with jitter, capped around 20s, 3–5 attempts.
  • 429, 500 and 503 are worth retrying. 400, 401 and 403 never are.
  • An SQS visibility timeout set too short re-delivers mid-inference and doubles the bill.
  • Throttle at account (~10,000 RPS), stage (1,000–5,000) and route (50–500) — route matters most.
  • SSE is one-way and resumes from Last-Event-ID; WebSockets are two-way and stateful.
  • Buffer 5–20 chunks and flush on size, time, or a sentence boundary.
  • Circuit breaker: trip at 50% of 10 requests, wait 30–60s, re-open at 10–20% traffic.
  • Degrade in steps: specialist model, general model with prompts, RAG, then plain rules.
  • X-Ray annotations let you filter traces later; p50 is typical, p99 is the pain.
  • Route on static config, on content, or on live metrics — and pass context when escalating.

2.5App Patterns & Dev Tools

  • Split by status code: 429 retries almost at once, 5xx backs off, 4xx never retries.
  • Timeouts must nest: model < Lambda ≤ API Gateway < client, or you get a bare 504.
  • Recursive summarization carries a rolling summary forward through long documents.
  • Keep WebSockets alive with a ping every 30–60s; idle limits are 10–30 minutes.
  • Skeleton screens and 50–200 ms render intervals make generation feel faster.
  • Streamed tokens are silent to a screen reader unless the container is an ARIA live region.
  • A similarity cache at 85–95% catches the same question asked differently.
  • Q Business serves knowledge seekers; Q Developer serves the codebase.
  • Bedrock Data Automation is the managed version of a hand-wired Textract/Transcribe pipeline.
  • Validate between agent handoffs or one agent's misreading propagates.
  • Carry context forward by extracting key facts — summaries drift.
  • Step Functions says what runs, EventBridge says when it starts.
  • If the retrieved chunks were already wrong, the model is innocent — fix retrieval.
Domain 3

Safety, Security & Governance

20% of the exam

3.1Input & Output Safety

  • Order the checks cheap to expensive: WAF, regex, Comprehend, Guardrails, then the model.
  • Each layer has a blind spot — WAF cannot read plain English, Guardrails cannot check ownership.
  • Rate limiting is a security control: it stops brute-forcing prompt variations.
  • Guardrails either block the whole answer or strip the offending part and keep the rest.
  • Moderate by role: strict for customers, looser for the team investigating abuse.
  • Accuracy stack: ground it, compare the answer to the sources, score confidence, bound the schema.
  • Grounding reduces hallucination. It does not eliminate it.
  • Text-to-SQL makes hallucinated numbers impossible — the database answers, not the model.
  • Schema catches an impossible value; similarity catches an invented rule. Different failures.
  • Guardrails write [PII]; a Lambda writes ****1234 with a checksum. You often need both.
  • Injection overrides instructions, jailbreak bypasses filters.
  • Indirect injection hides in a document RAG later retrieves — it fires for an innocent user.

3.2Data Security & Privacy

  • Bedrock is a public endpoint by default; interface VPC endpoints keep traffic internal.
  • Gateway endpoints exist only for S3 and DynamoDB — they cannot reach Bedrock.
  • Restrict IAM three ways: which models, which features, which operations.
  • ABAC scales where RBAC needs a new policy per condition.
  • Lake Formation controls columns, rows and cells inside a table; bucket policies cannot.
  • Comprehend reads text in flight, Macie scans what is already sitting in S3.
  • Bedrock does not train on your prompts or outputs.
  • Masking: redaction loses context, tokenization keeps references, pseudonymization reads naturally, FPE keeps the shape.
  • Anonymise a whole dataset by generalising, perturbing, or generating synthetic data.
  • Differential privacy needs a privacy budget, or repeated queries average the noise away.
  • k-anonymity means at least k−1 other people share your quasi-identifiers.
  • Over-anonymised data is useless data — check utility before shipping it.
  • Retention is policy, not code: lifecycle rules expire records on schedule.

3.3Governance & Compliance

  • A Model Card is the birth certificate and the report card — generate it in CI/CD or it rots.
  • Lineage is a graph of artifacts, actions and contexts; Glue tracks data, SageMaker tracks models.
  • CloudTrail data events are off by default — without them you cannot prove what was read.
  • Same model version plus same data version must reproduce the same output.
  • S3 versioning and Feature Store time travel are what make that reproducible.
  • SCPs only restrict, never grant — and not even root in a member account escapes them.
  • Tag everything, then grant on tags and deny anything untagged.
  • Whoever built the model cannot be the one who approves it.
  • Clarify computes DPPL, DI and DCR; a DI well below 0.8 is the red flag.
  • Bias is measured before training on the data and after training on the predictions.
  • Model Monitor watches four drifts: data quality, model quality, bias, feature attribution.
  • An alarm should shift traffic back to the last good version without waiting for a human.

3.4Responsible AI

  • Agent tracing exposes reasoning steps, retrieved chunks with scores, and tool payloads.
  • Hide the reasoning for a clean UI, or show it for trust — the notes argue both; context decides.
  • Uncertainty comes from token probabilities, ensemble disagreement, or calibration.
  • Demographic parity is crude; counterfactual fairness is the practical one for GenAI.
  • Equalized odds is the strictest: equal true and false positive rates across groups.
  • Correct but shorter answers for one group is still bias — completeness bias.
  • The judge model has its own bias: use rubrics, several judges, and human calibration.
  • Track tokens per demographic as a cheap proxy for unequal effort.
  • Translate policy into a control and keep the evidence: policy, spec, control, log.
  • Audit Manager with the GenAI Best Practices Framework collects the evidence for you.
  • Over-tight guardrails block legitimate clinical words — safety costs utility.
Domain 4

Operational Efficiency

12% of the exam

4.1Cost Optimisation

  • Input and output tokens are billed separately, and output costs more.
  • Count tokens before the call to predict cost and catch context overflow.
  • A summary is itself a model call — it only pays if the summary gets reused.
  • Models attend to the start and end, so put critical instructions first.
  • Drop 30% of prompt noise and you drop 30% of the input cost.
  • Model choice saves up to 80%; prompt work and caching save 10–20%.
  • Pick the cheapest model that clears the quality bar, not the best you can afford.
  • Batch inference is a cost feature (~50% off). Request batching is a throughput feature.
  • Provisioned throughput only beats on-demand above break-even; below it you buy idle capacity.
  • Semantic caching works at 85–95% similarity — 70% returns wrong answers, 99% is exact match.
  • Prompt caching discounts the static prefix ~90%, but only if the static part comes first.
  • Cache in tiers: in-memory, ElastiCache, then CloudFront at the edge.
  • A hit rate under 5% means the cache costs more than it saves.
  • You cannot have low latency, low cost and high throughput at once. Pick two.

4.2Performance Optimisation

  • Actual latency is the 8 seconds; perceived latency is the half second to first token.
  • Streaming is the cheapest way to feel faster without changing anything else.
  • Pre-computing turns a ~3,000 ms model call into a ~10 ms lookup.
  • DynamoDB is single-digit milliseconds; ElastiCache is sub-millisecond.
  • Parallel steps only help when they do not depend on each other.
  • HNSW is fast with high recall but memory-hungry; IVF scales on less memory.
  • ef_construction affects build time and quality only — it has no effect on query speed.
  • Rerank on relevance, recency and authority, not similarity alone.
  • Batching raises throughput and raises per-request latency. They pull apart.
  • Cap Step Functions Map concurrency so you do not throttle yourself.
  • Top-K is a fixed count; top-p adapts to how confident the model is.
  • Scale GPUs predictively — reactive scaling is too slow and requests time out first.
  • Inferentia is for inference, Trainium for training.
  • Evidently is for experiments, AppConfig is for feature flags.

4.3Monitoring

  • Every dashboard can be green while the model quietly lies.
  • Trace the whole prompt so you can tell retrieval, tool and model failures apart.
  • Bedrock model invocation logs are off by default — and once on they hold PII.
  • A 10× token spike means context leakage or an agent looping.
  • Hallucination is not a built-in metric: a judge plus a golden set makes it one.
  • Anomaly detection learns seasonality, so Monday mornings stop paging you.
  • A cost spike is a bug report — runaway loops and denial-of-wallet show up on the bill first.
  • Engineers want latency; the business wants escalation rate. Show both.
  • CloudTrail says who and when; CloudWatch Logs holds what was actually sent.
  • RUM catches the gap between 2 seconds on the server and 5 on the user's screen.
  • HTTP 200 is not success if the user immediately asks for a human.
  • A tool returning 200 with an empty body is fully successful and completely useless.
  • A high tool failure rate usually means a vague tool description, not broken code.
  • Restoring a vector index from a snapshot takes minutes; re-embedding takes days.
Domain 5

Testing, Validation & Troubleshooting

11% of the exam

5.1Evaluation Systems

  • Traditional ML has one right answer; generative output has many valid ones.
  • Score four independent things: relevance, factual accuracy, consistency, fluency.
  • Fluent and wrong is possible. So is accurate and irrelevant.
  • Never let a model judge its own output — self-preference bias.
  • Write the rubric down, or the judge drifts between runs.
  • Weight the dimensions by business risk, not evenly.
  • A/B compares two variants; canary ships one safely by degrees.
  • Customers spot unhelpful answers; only experts spot a confident, fluent, non-compliant one.
  • Watch where people abandon, rephrase, or ask for a human — that is the real signal.
  • Put the quality gate in the pipeline so a bad build blocks itself.
  • Change the evaluation dataset and the old scores are no longer comparable.
  • Evaluate retrieval alone and end to end — that is how you tell whose fault it is.
  • Citations need precision (right source) and coverage (every claim backed).

5.2Troubleshooting

  • Context overflow truncates silently — no error, and the answer still sounds confident.
  • Fix it with semantic chunking, a sliding window, and the important part first.
  • Classify failures before fixing: 400 is you, 429 is capacity, 500 is them.
  • About 40% of 'API failures' never reached the model — malformed client payloads.
  • Tracing found the bottleneck in auth middleware, not in the model everyone blamed.
  • Shed low-priority load so urgent requests keep their capacity.
  • More instructions can make a prompt worse — they start competing.
  • Version prompts and roll back automatically when accuracy drops.
  • Use chain-of-thought as a diagnostic to see where reasoning broke.
  • Irrelevant retrieval is usually domain mismatch, embedding drift, or chunks cut badly.
  • LSH is fastest and least accurate, HNSW best balanced, IVF scales, PQ is tiny and lossy.
  • Domain fit of the embedding model matters more than its dimensionality.
  • Unsubstituted {{variables}} in output mean the template never rendered.
